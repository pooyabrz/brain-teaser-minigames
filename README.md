A collection of interactive **brain training minigames** 🧠🎮 built with **React** (frontend) and **Node.js** (backend).  
Challenge yourself with puzzles, logic games, and memory boosters — all in one platform!

---

## ✨ Features

- 🎲 Multiple minigames (memory, logic, math, puzzles, etc.)  
- 🧑‍💻 Full-stack app: React (frontend) + Node.js/Express (backend)  
- 💾 PostgreSQL database for storing scores and player profiles  
- 🔐 User authentication (sign-up, login, leaderboard)  
- 🎨 Clean UI with responsive design  
- 📊 Real-time scoreboard / leaderboards

## 🛠️ Installation & Run

### 1. Clone the repository
```bash
git clone https://github.com/pooyabrz/brain-teaser-minigames.git
cd brain-teaser-minigames
```
### 2. Setup Backend (Node.js)
```bash
cd server
npm install
# Copy .env.example → .env and fill database credentials
npm run dev
```
### 3. Setup Frontend (React)
```bash
cd client
npm install
npm start
```
### App should now run at: http://localhost:3000
